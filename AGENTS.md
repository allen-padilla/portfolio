# Project notes

- npm only. Conventional Commits (`type(scope): subject`, imperative, lowercase, no trailing period).
- Content model: `content/projects.ts` is the source of truth for project metadata. MDX bodies in `content/projects/<slug>.mdx` are body-only with **no frontmatter**. Only `##` headings become table-of-contents entries; ids come from `github-slugger`, matching `rehype-slug`.
- `@next/mdx` runs under Turbopack, so remark/rehype plugins in `next.config.ts` must be **string names**, not imported functions.
- Design tokens live in `app/globals.css` under `@theme`, based on the coolors palette 2b2d42-8d99ae-edf2f4-ef233c-d90429. Use them (`bg-paper`, `bg-paper-2`, `text-ink`, `text-muted`, `text-gray`, `border-rule`, `text-accent`, `text-accent-2`, `font-serif|sans|mono`, `text-display|title|h2|label`) rather than raw hex values. `text-gray` (#8d99ae) fails AA on paper, so use it only for decoration, never for text.
- Light theme only. Sharp corners, hairline rules, no shadows. The header (`components/layout/TopBar.tsx`) is a non-sticky bar: name and role side by side in mono caps, sentence-case nav (Work, About, Resume, GitHub, Email) with a red underline on Work, ink rule beneath. About scrolls to `#about` on the home page. The footer (`Footer.tsx`) is the name as a large serif wordmark with a red full stop over one row of links.
- The only client component is `components/case-study/Toc.tsx`. Keep the home page free of client JS. The animated Canopy card (`components/home/CanopyFeature.tsx`, styles under `.cf-*` in `globals.css`) is pure CSS keyframes; its mark geometry is copied from `LeafMark.svelte` in the joincanopy-web repo (`~/Dev/Ideas/joincanopy-web`) and its choreography from that site's hero. The Operations Platform card (`components/home/OpsFeature.tsx`, `.of-*`) follows the same pattern with a text wordmark. `components/home/WorkGrid.tsx` is the home page's only project section (it replaced the feature band plus the numbered ledger on 2026-09-04) and picks a card by slug; the ledger (`ProjectIndex`/`ProjectRow`) still renders `/projects`. Three more cards follow the same pattern: `MemberFeature` (`.mf-*`, 15s), `GradFeature` (`.gf-*`, 14s), `MvlpFeature` (`.vf-*`, 17s), `HomelandFeature` (`.hf-*`, 18s; its background is a ~830 KB muted autoplay MP4 at `public/projects/homeland-map/card-loop.mp4`: exactly one revolution at 2x speed, captured frame by frame under a faked clock so it is smooth at 24 fps and loops seamlessly, with the wide still shown instead under prefers-reduced-motion). Their keyframes are written by `node scripts/feature-keyframes.mjs` into the `@generated feature-keyframes` block in `globals.css`; change timings in the script's spec, never in the CSS. `lib/shots.ts` picks a card's screenshots by file stem. Any other project with images gets the plain image treatment. Both cards loop: every part is one long `infinite` animation (16s Canopy, 13s Ops, offset so they drift apart) whose keyframes are percent offsets of the cycle, with a `.cf-stage`/`.of-stage` fade in the last 0.6s. The keyframe blocks were generated by a script; if you change timings, regenerate rather than hand-edit percentages.
- OG images are generated in `lib/og.tsx` from fonts in `assets/og/`, read from `process.cwd()` at build time.
- Route transitions use React's `ViewTransition` (from the canary React that Next bundles; types via `react-canary.d.ts`). `app/template.tsx` gives every navigation an exit/enter crossfade, and project titles are named `project-title-<slug>` in both `ProjectRow` and `CaseStudyHeader` so they morph. WorkGrid card titles carry the name too, which is fine because the ledger no longer renders on the home page (a name must be unique per page). CSS lives at the end of `globals.css` under "Route transitions".
